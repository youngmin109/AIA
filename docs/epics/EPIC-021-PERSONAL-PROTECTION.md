# EPIC-021 — 개인용 정책·복구 지점·데스크톱 가디언

사용자 승인 범위: 정책 네 가지의 실제 규칙 설명, 사용자 지정 정책 편집·검증·저장·다음 실행 적용,
작업 완료 후 자동 및 사용자 수동 복구 지점, 기록에서 지점 선택·미리보기·반복 복구,
앱 최소화 중에도 남는 독립 Windows 가디언 창. 기존 테마·센서·차단 권한을 유지한다.

- 최초 체크포인트는 자동 대응의 기준으로 계속 고정한다. 추가 지점은 수동 복구용이다.
- 자동 저장은 app-server 작업 완료, 대기 상태, 건강한 센서·Hook, 정책 위반/미확정 판정 없음,
  지원 범위 밖 도구 승인 없음 및 파일 변경 정착을 확인한 뒤 시도한다. 저장 중 새 요청은 거절하고 재시도를 안내한다.
- 복구 지점 검증은 저장 파일의 일관성이지 코드의 안전성 보증이 아니다. 외부 작성자·이벤트 지연은 한계다.
- 실행 중 복구는 거절한다. 종료 후 Lease, 미리보기 해시, 지점 소유권·해시를 재검증한다.
- 원래 결과 묶음은 변경하지 않는다. 추가 지점과 반복 복구 이력은 별도 검증 가능한 기록으로 남긴다.
- 정책 JSON 네 가지는 변경하지 않는다. 사용자 지정은 실제 엔진 형식과 우선순위를 사용한다.
- 가디언은 표시·탐색만 담당한다. 서버 연결이 끊기면 확인 필요로 표시한다. 앱 완전 종료 시 함께 종료한다.
- 새 의존성, 로그인, 기업 정책 수명주기, 앱 종료 후 상주 서비스는 범위 밖이다.

검증: Python 회귀/새 통합 테스트, 프론트엔드 테스트·lint·빌드, Windows 패키지 빌드·실행.

후속 사용자 승인: 복잡한 별도 정책 상세보기 제거, 정책 5종 한 줄 배치(좁은 창은 가로 스크롤),
펫 크기 설정 및 상태 상자 안 작은 열기·숨기기 버튼. 보호·복구 의미는 변경하지 않는다.
