# AIA: AI 코딩 에이전트를 위한 런타임 보증

AIA는 AI 에이전트 자체를 제어 대상으로 다룹니다. 에이전트의 설명을 신뢰하는 대신, 실행 중 관찰한 동작과 독립적인 증거를 정책에 대조하는 Zero Trust 런타임을 지향합니다.

## AIA가 하는 일

1. **에이전트 런타임 관찰:** 보호 실행 중 지원되는 파일·명령·프로세스 동작을 관찰합니다.
2. **실행 동작 검증:** 에이전트의 자기 보고가 아니라 관찰된 증거를 바탕으로 판단합니다.
3. **독립 센서 증거 결합:** Hook은 요청을, Process는 관찰된 프로세스를, File은 관찰된 변경을 기록합니다.
4. **증거에 근거한 제어:** 귀속을 `EXACT`, `PROCESS`, `TEMPORAL`, `UNKNOWN`으로 구분하며, PROCESS 증거만으로 파일 작성자를 식별하지 않습니다.
5. **보증 단계 연결:** 지원 범위 안에서 정책 평가, 집행, 체크포인트 복구, SHA-256 무결성 검증을 각각 구분해 기록합니다.
6. **추적 가능한 증거 체인:** 증거가 있는 경우 도구 요청, 프로세스·파일 관찰, 정책 결정, 집행, 복구를 연결합니다.

정책 위반만으로 에이전트를 종료하지 않습니다. 자동 격리에는 EXACT 귀속과 검증된 프로세스 식별이 모두 필요합니다. 지원 범위와 주장 한계는 [주장 기준표](docs/validation/CLAIM-MATRIX.md)와 [제한사항](docs/LIMITATIONS.md)을 확인하세요.
