보호 실행 시작

먼저 작업 폴더와 보호 정책을 선택합니다. 준비가 끝나면 AIA가 보호된 Codex 세션을 열고, 실행 전 도구 요청과 파일 변화를 기록합니다.

1작업 폴더 선택사용자가 만든 Workspace를 지정합니다.
2정책·기준점 준비정책을 고정하고 Checkpoint를 만듭니다.
3Codex 보호 실행지원되는 도구 요청을 실행 전에 평가합니다.
4결과 확인차단·허용·증거·무결성을 결과로 남깁니다.

첫 단계
작업 방식 AIA가 먼저 보호된 Codex 세션을 열고, 세션 안에서 원하는 작업을 입력합니다. 아래 작업 요청을 보호 준비가 끝난 뒤 Codex에 한 번 전달합니다.
Codex 화면 대시보드·Codex 작업창·세 센서 상태를 한 화면에 표시합니다. 기존 호환 모드입니다. Codex 작업 화면을 별도 창에서 엽니다.
로컬 전용: 이 콘솔은 기본적으로 127.0.0.1에서만 열립니다. 처음에는 테스트용 Workspace를 사용하고 작업 요청에 비밀정보를 넣지 마세요.
현재 지원 범위: Windows 11 · Codex CLI · AIA Protected Run · Hook matcher는 모든 로컬 Hook 대상(*)을 받으며, AIA가 의미를 해석하는 도구는 아래 목록으로 제한됩니다. 목록 밖 도구는 보호 실행에서 거부됩니다.
