보호 실행 시작

먼저 작업 폴더와 보호 정책을 선택합니다. 준비가 끝나면 AIA가 보호된 Codex 세션을 열고, 실행 전 도구 요청과 파일 변화를 기록합니다.

1작업 폴더 선택사용자가 만든 Workspace를 지정합니다.
2정책·기준점 준비정책을 고정하고 Checkpoint를 만듭니다.
3Codex 보호 실행지원되는 도구 요청을 실행 전에 평가합니다.
4결과 확인차단·허용·증거·무결성을 결과로 남깁니다.

처음 사용하는 경우
  1. Codex 화면에서 /hooks를 열고 AIA Hook을 검토·신뢰합니다.
  2. PowerShell에서 uv run aia hook verify를 실행합니다.
  3. 이 화면에서 다시 검사를 누른 뒤 보호 실행을 시작합니다.
작업 시작 방식 AIA가 먼저 보호된 Codex 세션을 열고, 세션 안에서 원하는 작업을 입력합니다. 아래 작업 요청을 보호 준비가 끝난 뒤 Codex에 한 번 전달합니다.
로컬 전용: 이 콘솔은 기본적으로 127.0.0.1에서만 열립니다. 처음에는 테스트용 Workspace를 사용하고 작업 요청에 비밀정보를 넣지 마세요.
현재 지원 범위: Windows 11 · Codex CLI · AIA Protected Run · PreToolUse 기반 Bash/apply_patch/Edit/Write 및 등록된 파일 읽기 MCP
